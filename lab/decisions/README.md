# Decision records

Each hard-to-reverse choice gets one file, `NNNN-short-title.md`, numbered in order. Link records as `[[NNNN-short-title]]` from the notebook, STATE.md and other records.

If a new decision changes an old one, update the old record's Status, and its text if needed, in the same commit. Two records must never disagree.
