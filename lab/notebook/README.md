# Lab notebook

This is an append-only session log. There is one file per month (`YYYY-MM.md`) and one entry per session, with the newest at the bottom. Never edit an old entry. If one turns out to be wrong, say so in a new entry.

The notebook is never auto-loaded; STATE.md points into it. Search it by tag or keyword:

    grep -rn "#publications" lab/notebook/

Tags in use: `#cleanup` `#content` `#publications` `#cv` `#design` `#mobile` `#performance` `#seo` `#deploy` `#workflow`. Add new ones when needed and keep them lowercase.

## Entry template

    ## YYYY-MM-DD — <session focus>
    **Tags:** #topic #tag2
    **Did:** <what was tried/built/reasoned — include dead ends, not just wins>
    **Results / where:** <changed pages/files, live URLs, before/after numbers>
    **Decisions:** <[[0004-title]] or "none">
    **Next:** <handoff for next session>
    **Commit:** <short SHA or "uncommitted">

Keep entries informative but tight. They are not a transcript.
